## 🚀 About Me

I am a Software Engineer focused on building robust **Backend Systems**, **Real-Time Data Services**, and **High-Performance Game Infrastructure**. My work revolves around **Clean Architecture**, **Domain-Driven Design (DDD)**, memory optimization, and scalable real-time communication protocols.

- 🛠️ **Core Technologies:** C# (.NET 10 / .NET 9), Python 3.12, FastAPI, SignalR, Docker, EF Core, Redis.
- 📐 **Architectural Focus:** Clean Architecture, Microservices, Event-Driven & Real-Time WebSockets, Profiling & Benchmarking.
- 🎮 **Game Systems:** Unity 2D Multiplayer Infrastructure, Spatial Messaging, Real-time Client-Server State Sync.
- ⚡ **Performance & Quality:** Automated unit & integration testing (xUnit, pytest), memory-level profiling (BenchmarkDotNet).
