## 🔐 How I approach security & quality

- **Shift left:** security and tests are built in from the first commit, not bolted on at the end.
- **Threat-model first:** I map features to OWASP Top 10 risks before writing a single test case.
- **Evidence over opinions:** every finding ships with severity, step-by-step reproduction, impact and a concrete mitigation.
- **Verify the fix:** regression testing confirms each finding is closed without breaking the product.
- **Document everything:** test plans, risk reports and runbooks the team can reuse.
